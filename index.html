🎯 Prompt Inbox

Wyślij prompt do swojego agenta

Z dowolnego urządzenia — telefon, tablet, inny komputer. Prompt trafia do GitHub Issues, skąd agent go odczytuje i realizuje.

0/4000
Wpisz prompt (co najmniej 10 znaków), zanim wyślesz.
1

Wypełnij formularz — wybierz projekt i wpisz prompt.

2

GitHub — otworzy się gotowe zgłoszenie. Kliknij „Submit new issue”.

3

Realizacja — prompt czeka w BartoszOsiej/prompt-inbox; agent go odczytuje, realizuje i zamyka.

4

Odpowiedź — zobaczysz ją w czacie z agentem.
